# Praveen Sewing Machines — Frontend

This is a frontend-only React + Vite starter for the Praveen Sewing Machines website.

Getting started:

1. Install dependencies:

```bash
npm install
```

2. Run development server:

```bash
npm run dev
```

3. Build production bundle:

```bash
npm run build
```

Notes:
- This project is intentionally frontend-only. Do not add backend code here.
- Replace placeholders in `src/data/siteConfig.js` with real business info.
 - For production readiness:
	 - Update `index.html` meta tags and `src/data/siteConfig.js` with exact business details.
	 - Add real optimized images to `src/assets/` and `src/assets/logos/` for brands.
	 - Deploy to Vercel by connecting the repository and using the `npm run build` output.
	 - Check `robots.txt` and `sitemap.xml` and update URLs to your production domain.
